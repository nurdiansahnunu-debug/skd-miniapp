# SKD Mini App

Tampilan Mini App Telegram untuk bot SKD Penawaran & HPP. © 2026 Sinergi Karya Digital.

Repo ini hanya berisi halaman tampilan. Tidak ada data customer, harga, HPP, token, atau kunci.
Data diambil dari web app Apps Script setelah akun Telegram dicek (tanda tangan resmi Telegram
dan daftar pengguna terdaftar). Membuka halaman ini di luar Telegram tidak menampilkan data apa pun.
